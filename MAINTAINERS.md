## Becoming a Contributor

Apertale welcomes contributions from the creative engineering and 3D web community! To contribute:
1. Fork the repository (`authrain-cloud-abdullahformuli/apertale`)
2. Create your feature branch (`git checkout -b feature/interactive-spread`)
3. Commit your enhancements
4. Open a Pull Request
